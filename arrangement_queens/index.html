Cámaras de reinas

Si la columna de cada reina es un número real xi, cada amenaza posible es un hiperplano de ℝN. Esos hiperplanos parten el espacio en cámaras. Toda solución de las N reinas es un punto entero dentro de una cámara, sin tocar ninguna pared.

xi − xj = 0  (columna)  ·  xi − xj = i − j  (diagonal)  ·  xi − xj = j − i  (antidiagonal)

El polinomio característico

χN(q) cuenta las formas de poner N reinas en N filas de un tablero toroidal q×q, para primos q grandes (método de cuerpos finitos). Por Zaslavsky, |χ(−1)| es el número de cámaras y |χ(1)| el de cámaras acotadas. Cada polinomio se interpoló con N primos y se comprobó con dos primos más.

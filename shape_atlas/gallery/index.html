Atlas de epiciclos de las N-reinas

Cada tablero con una reina por fila (columna cr en la fila r) se dibuja como una cadena de N vectores giratorios: z(t) = Σr exp(i·((r+1)·t + 2π·cr/N)), t ∈ [0, 2π). N = 8 salvo donde se indica.

Resultado en una línea. En la codificación fila→frecuencia ningún rasgo de la forma distingue las soluciones: la forma (salvo giro) es idéntica para los N² tableros cr + a(r+1) + b mod N, y en N = 8 las 62 formas que dibujan las 92 soluciones las dibujan también 612 permutaciones que no son solución (techo de precisión 0,13 para cualquier clasificador que solo vea la forma). Incluso la curva exacta, con su orientación, la comparte un tablero malo en 38 de los 92 casos. Lo único exacto son puntos marcados del parámetro (z(2πk/N)), que solo hablan de diagonales módulo N (toroidal). Si las diagonales se meten en la frecuencia (E2), el área encerrada se vuelve un testigo exacto. Ver el README para los detalles.

2 · Gemelos: misma forma, distinto estatus

Para un representante de cada clase fundamental: la solución, el mismo tablero con las columnas giradas c+1 mod 8 (la curva gira 45°, forma idéntica) y la primera cizalla c + a(r+1) que sigue siendo permutación (curva idéntica, solo cambia dónde está t = 0). Ninguno de los gemelos es solución. Esto es lo que hace imposible un criterio exacto basado solo en la forma (E0).

3 · Flores lineales y toroidales

c = a·r mod N para todas las a. Todas son la misma curva (núcleo de Dirichlet girado): N−1 pasos por el origen y N−1 lóbulos, uno grande y N−2 pequeños. Solo las a ∉ {0, ±1} son solución; la forma no lo sabe. Para N = 7 y 11 todas las soluciones toroidales son lineales; en N = 13 aparecen toroidales no lineales (última fila).
